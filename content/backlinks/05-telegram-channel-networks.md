Quick network guide for everyone selling USDT with us:

TRON (TRC-20) — addresses start with T. Confirms in about a minute. The
default everywhere in Asia.

BSC (BEP-20) — addresses start with 0x. Confirms in 15-25 seconds and
exchange withdrawal fees are usually lower. If you want the order page to
flip to "detected" almost as soon as your exchange says "completed", pick
this one.

The only rule that matters: the network you pick on your exchange must
match the address format on your order. T address = TRON. 0x address =
BSC. Check the first two characters before you hit send — that one glance
prevents the only real mistake in this whole process.
